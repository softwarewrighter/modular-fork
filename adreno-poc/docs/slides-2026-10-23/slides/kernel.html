IR and kernel

Typed XIR, then one fused OpenCL kernel

threshold.xir, the Float path

%l = const f64 [8] 1.0 2.0 ... 8.0

%r = const f64 [] 4.0

%div = map div %l %r

%sub = map sub %div %r_2

%gt = map gt %sub %r_3

%f = cast f64 %gt

%mul = map mul %sub %f

%max = map max %sub %r_4

Library calls inlined, the range folded to a constant, every array operation one typed node. The comparison yields a Bool, the cast makes a mask, the multiply is the threshold, the max is ReLU.

threshold.cl, generated

__kernel void k0(__global const float* b_l, ...) {

  size_t i = get_global_id(0);

  if (i >= 8) return;

  float t_div = (b_l[i] / 4.0f);

  float t_sub = (t_div - 1.0f);

  int t_gt = (t_sub > 0.5f);

  float t_f = (float)t_gt;

  float t_mul = (t_sub * t_f);

  float t_max = fmax(t_sub, 0.0f);

  ...

Consecutive maps of one shape fuse into one kernel; the IR temporaries become register expressions. The guard matters because the launch rounds up to a work-group. Floats are f32 on this no-fp64 device, Ints i64.

xetal-gpu lower and xetal-gpu kernel, run on the board; the full files are in the evidence directory

The emitter is the one that has been running on Kepler Quadros and RTX 5060 Tis for weeks. The only thing specific to this board is a schedule file, which we will get to.
