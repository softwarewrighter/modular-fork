The question

What does it take to run parallel code on this GPU, written in Mojo and written in X_eTaL?

Not a benchmark. A proof: the same answer the language's own evaluator gives, produced by the Adreno, with every intermediate form captured so the path can be read.

The question is deliberately modest. I am not after speed on a 845 MHz embedded GPU. I want correctness, provenance and a readable path from source to the instructions the GPU executed, for both languages.
