The same five operations, register names aside. One visible difference: X_eTaL folds the threshold 0.5 into the instruction as an immediate, while Mojo passes t as a kernel argument, so the Adreno reads it from constant register c9.z.

This is the punch line. Two very different source languages, two different routes into the driver, and the Freedreno compiler produced the same instruction sequence for the activation itself. The surrounding code differs: the X_eTaL kernel also computes x from the range and carries an Int path.
