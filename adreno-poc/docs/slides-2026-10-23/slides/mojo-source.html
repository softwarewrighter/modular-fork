The Mojo host

One exported function: fill, call, check

from std.ffi import external_call

 

# C launcher provides storage; this exported function needs no Mojo startup.

@export("mojo_adreno_demo")

def mojo_adreno_demo(

    inputs: Pointer[Float32, MutAnyOrigin],

    outputs: Pointer[Float32, MutAnyOrigin],

    expected: Pointer[Float32, MutAnyOrigin],

    n: Int,

) abi("C") -> Int32:

    if n != 8:

        return -1

    for i in range(n):

        var x = Float32(i + 1) / 4.0 - 1.0

        inputs[unsafe_offset=i] = x

        expected[unsafe_offset=i] = x

        var mask = Float32(1.0) if x > 0.5 else Float32(0.0)

        expected[unsafe_offset=n + i] = x * mask

        expected[unsafe_offset=2 * n + i] = max(x, Float32(0.0))

    var status = external_call["adreno_threshold_v1", Int32](

        inputs, outputs, n, 3 * n

    )

    if status != 0:

        return status

    var failures: Int32 = 0

    for i in range(3 * n):

        if outputs[unsafe_offset=i] != expected[unsafe_offset=i]:

            failures += 1

    return failures

What Mojo does

Builds the same eight inputs as the X_eTaL program, computes its own threshold and ReLU reference on the CPU, calls the bridge, and counts mismatches over all 24 values.

What the bridge does

Checks for exactly one Qualcomm GPU, builds a checked XIR program, and runs it through X_eTaL-gpu's planner and OpenCL runtime.

What it compiles to

An AArch64 object with one unresolved symbol, adreno_threshold_v1, linked with the C launcher. No Mojo runtime.

adreno-poc/mojo/threshold.mojo, the whole file; Mojo 1.2.0.dev2026101305, pinned

Here Mojo is the host program only. The GPU kernel comes from X_eTaL-gpu's emitter, through a hand-written XIR string in the Rust bridge. The next section is the step past this: a kernel written in Mojo itself.
