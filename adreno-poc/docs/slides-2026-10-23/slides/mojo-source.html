The Mojo

One exported function: fill, call, check

@export("mojo_adreno_demo")

def mojo_adreno_demo(inputs, outputs, expected: Pointer[Float32, MutAnyOrigin],

n: Int) abi("C") -> Int32:

for i in range(n):

var x = Float32(i + 1) / 4.0 - 1.0

inputs[unsafe_offset=i] = x

expected[unsafe_offset=i] = x

var mask = Float32(1.0) if x > 0.5 else Float32(0.0)

expected[unsafe_offset=n + i] = x * mask

expected[unsafe_offset=2 * n + i] = max(x, Float32(0.0))

var status = external_call["adreno_threshold_v1", Int32](inputs, outputs, n, 3 * n)

if status != 0: return status

var failures: Int32 = 0

for i in range(3 * n):

if outputs[unsafe_offset=i] != expected[unsafe_offset=i]: failures += 1

return failures

What Mojo does

Builds the same eight inputs as the X_eTaL program, computes its own threshold and ReLU reference on the CPU, calls the bridge, and counts mismatches over all 24 returned values.

What the bridge does

Verifies there is exactly one Qualcomm GPU, builds a checked XIR program with a dynamic input, and runs it through X_eTaL-gpu's planner and OpenCL runtime.

What it compiles to

An ELF64 AArch64 object with one unresolved symbol, adreno_threshold_v1, linked by the ARM64 GCC with the launcher. The disassembly shows fcmp, fcsel and fmul for the reference, then bl to the bridge.

adreno-poc/mojo/threshold.mojo, condensed for the slide; Mojo 1.2.0.dev2026101305, pinned

Signatures are shortened to fit; the real file declares each pointer parameter. The point to make out loud: Mojo generated the code that runs on the A53, and that code was never linked against Mojo's runtime, which is what let it run on a CPU without LSE atomics.
