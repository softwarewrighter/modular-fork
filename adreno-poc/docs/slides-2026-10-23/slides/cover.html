X_eTaL and Mojo on the Adreno 702

One day, one dev board: array code from two languages, running on the GPU of an Arduino UNO Q and checked against an independent oracle.

Mike Wright

Software Wrighter Lab

2026-10-23

Today I want to show how two very different languages, Modular's Mojo and my own X_eTaL, ended up running array code on the same low-end GPU in a single day. The board is an Arduino UNO Q. The GPU is a Qualcomm Adreno 702 that neither language's toolchain officially supports.
