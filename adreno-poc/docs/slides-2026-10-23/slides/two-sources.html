Whole-array functions. No threads, no indices, no buffers: the compiler finds the parallelism and writes the kernel.

Mojo: one kernel, one thread per element

# mojo/activation_gpu.mojo

def activations(x, threshold, relu: Pointer[...],

t: Float32, n: Int32):

var i = Int(block_idx.x * block_dim.x + thread_idx.x)

if i < Int(n):

var v = x[unsafe_offset=i]

var mask = 1.0 if v > t else 0.0

threshold[unsafe_offset=i] = v * mask

relu[unsafe_offset=i] = max(v, 0.0)

Written as for Apple or NVIDIA. The host opens a DeviceContext, copies x, launches with grid and block sizes, copies back.

Same formula three ways: x × float(x > t) in X_eTaL, v * mask in Mojo, gt, cast, mul in XIR. Mojo types shortened to fit.

This is the comparison I wanted from the start. X_eTaL states the activation over whole arrays and the compiler finds the parallelism. Mojo states one thread's work explicitly. Both describe exactly the same arithmetic, and from here on both reach the same GPU.
