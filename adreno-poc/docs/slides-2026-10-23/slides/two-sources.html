Mojo: the kernel, 15 of the file's 61 code lines

def activations(

    x: Pointer[Float32, ImmutAnyOrigin],

    threshold: Pointer[Float32, MutAnyOrigin],

    relu: Pointer[Float32, MutAnyOrigin],

    t: Float32,

    n: Int32,

):

    """One thread per element: threshold(x, t) = x * (x > t),

    relu(x) = max(x, 0)."""

    var i = Int(block_idx.x * block_dim.x + thread_idx.x)

    if i < Int(n):

        var v = x[unsafe_offset=i]

        var mask = Float32(1.0) if v > t else Float32(0.0)

        threshold[unsafe_offset=i] = v * mask

        relu[unsafe_offset=i] = max(v, Float32(0.0))

One thread's work, written out. The host setup, launch, readback and check are the other 46 lines, on the next two slides.

Same formula three ways: x × float(x > t) in X_eTaL, v * mask in Mojo, gt, cast, mul in XIR

X_eTaL states the activation over whole arrays and the compiler finds the parallelism; its host work lives in the xetal-gpu tool, about 9,800 lines of Rust, not in the program. Mojo states one thread's work explicitly and puts the host work in the program, as the next two slides show in full.
